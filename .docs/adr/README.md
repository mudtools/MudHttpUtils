# Architecture Decision Records (ADR)

本目录存放 Mud.HttpUtils 项目的架构决策记录（Architecture Decision Records）。

## 什么是 ADR？

ADR 是轻量级的文档，用于记录重要的技术决策及其背景、权衡和后果。每个 ADR 包含：
- **背景**：为什么需要做出这个决策
- **备选方案**：考虑过的选项及其优缺点
- **决策**：最终选择及理由
- **后果**：正面和负面影响


## 如何使用

### 创建新 ADR

1. 复制 `ADR-000-模板.md` 为新文件（如 `ADR-001-xxx.md`）
2. 填写所有必填字段
3. 在代码注释中引用：`详见 ADR-XXX`
4. 更新本索引表格

### 引用 ADR

在代码中使用以下格式：

```csharp
/// <remarks>
/// 生命周期选 Transient，避免多管理器共享缓存键导致串扰。详见 ADR-012。
/// </remarks>
```

### 更新 ADR

- 当决策被推翻或修改时，创建新版本（v1.1, v1.2...）
- 在"变更记录"表中说明修改内容
- 如完全废弃，标记状态为"已废弃"并创建新 ADR 替代
