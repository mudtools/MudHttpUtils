### 前置改造（与 M1 同批，两个任务）

**T-0.1**：把 `Tests/Mud.HttpUtils.Integration.Tests` 与 `Tests/Mud.HttpUtils.OpenTelemetry.Tests`
加入 `test.ps1` 的 `$TestProjects`（`test.ps1:50-55`）。

理由：#5（Span/指标脱敏）、#6（tag 基数）、#10（超时异常）、#13（流式三态）等验收**必须**依赖
`ActivityListener` / `MeterListener` 断言；当前不跑这些项目等于验收门禁缺位。

> 注意：`Integration.Tests` 已声明
> `[assembly: Xunit.CollectionBehavior(DisableTestParallelization = true)]`
> （`GlobalUsings.cs:15`，因进程级静态 `MudHttpMeter` 会被并发 listener 捕获）。
> **本次新增的指标断言用例必须遵守该约束**，不得改回并行。

**T-0.2（新增）**：增强 `Mud.HttpUtils.Testing/StubHttp.cs`：

| 能力 | 用途（对应用例） | 设计 |
|------|------------------|------|
| 无 `Content-Length` 的 chunked 响应 | T-1.1/T-1.2/T-9.1/T-26.1/T-29.1 | 新增 `WithStreamContent(Stream/byte[], contentType)`，用自定义 `HttpContent`（`SerializeToStreamAsync` 直写、不设 ContentLength）替代 `StringContent` |

## 3. CI 门禁

### 3.1 每批次（M1/M2/M3）必须全绿

```powershell
# 1) 全量构建（4 TFM 全部编译，暴露 #if 分支问题）
dotnet build Mud.HttpUtils.slnx -c Release

# 2) 单元测试（T-0.1 后含 Integration / OpenTelemetry）
.\test.ps1 Release

# 3) Public API 分析器（RS0016 等）必须零错误 —— 由第 1 步构建覆盖

# 4) 打包冒烟（验证 NuGet 包结构）
.\pack.ps1
```

### 3.2 合并到主干前（每批完成时）

```powershell
# Native AOT 发布 + 运行验证（net8.0 / net10.0，严格模式 + 全裁剪）—— test.ps1 已支持这些开关
.\test.ps1 Release -AOT -AotStrictMode -FullTrim
```

覆盖 `Demos/AotVerificationDemo` 与 `Demos/AotFullTrimVerificationDemo`，输出必须包含 `AOT_OK`。

### 3.3 CI 现状与建议（验证修订）

现有 `.github/workflows/ci.yml` 已有 6 个 job：`test`（4 个测试项目 × SDK 8/10）、`build-demos`、
`aot-publish`（linux/win × AOT_OK 硬门禁）、`aot-packageref`、`build-and-pack`、`publish-nuget`。
对照原建议：

| 原建议作业 | 现状 | 行动 |
|------------|------|------|
| `build-matrix` | **部分**：`test`/`build-demos` 是项目矩阵，但无 windows 普通构建 | CI 的 `test` job 已隐式构建各 TFM（dotnet test 会 build）；无需新增独立 job，在 `test` job 增补 `runs-on: windows-latest` 一项即可（可选） |
| `publicapi` | **缺失**：无 `-warnaserror` 专项 | 仓库 `TreatWarningsAsErrors=false`（Directory.Build.props:6）。**改为**：在 `test` job 增加一步 `dotnet build -c Release -p:TreatWarningsAsErrors=true`（仅公共包项目），RS0016 等 PublicAPI 未同步即失败 |
| `aot` | **已实现**（`aot-publish` + `aot-packageref`） | 无需新增；`test.ps1` 本地等价命令见 3.2 |
| `benchmark-gate` | 未实现 | 不做（阈值告警维护成本高，手动跑 Benchmarks 即可，见 3.4） |
